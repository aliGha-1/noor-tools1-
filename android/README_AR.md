# مشروع نور تولز للأندرويد — مصدر تجهيز APK

هذا مشروع Android Studio يضم نسخة نور تولز محليًا داخل التطبيق، ولذلك لا يحتاج إلى رابط إنترنت لتشغيل الواجهة بعد تثبيت APK. التخزين يتم على نفس الهاتف باستخدام localStorage داخل WebView. النسخة لا تزامن البيانات تلقائيًا مع الكمبيوتر.

## إنشاء ملف APK
1. ثبّت Android Studio على كمبيوتر Windows أو macOS أو Linux.
2. افتح Android Studio واختر **Open** ثم اختر مجلد `Noor_Tools_Android_APK_Project` بعد فك ضغط الحزمة.
3. اسمح له بتنزيل مكونات Android Gradle Plugin وAndroid SDK عند الطلب (هذا يحتاج إنترنت أثناء التجهيز الأول فقط).
4. من القائمة اختر **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
5. بعد انتهاء البناء، استخدم زر **Locate** للوصول إلى ملف APK، وغالبًا يكون داخل `app/build/outputs/apk/debug/app-debug.apk`.
6. انقل APK إلى هاتف Android وثبّته. قد يطلب الهاتف السماح بالتثبيت من هذا المصدر.

## بيانات الدخول
كلمة المرور الافتراضية: `1234` — غيّرها من الإعدادات.

## حفظ البيانات والنسخ الاحتياطي
- بيانات التطبيق تبقى على الهاتف نفسه ولا تتزامن مع نسخة Windows.
- تصدير JSON وCSV مُعدّ للحفظ في مجلد Downloads في Android.
- استخدم «تنزيل نسخة احتياطية JSON» بانتظام، واختبر استعادة النسخة قبل الاعتماد على بيانات حقيقية.
- حذف التطبيق أو مسح بياناته قد يؤدي إلى فقد البيانات المحلية؛ احتفظ بنسخة خارج الهاتف.

## ملاحظات مهمة
- هذه حزمة مصدر Android Studio وليست ملف APK مبنيًا مسبقًا. بيئة البناء هنا لا تحتوي على Android SDK، لذلك لم يتم إنتاج APK قابل للتثبيت داخل هذه الحزمة.
- كلمة المرور قفل واجهة محلي وليست حماية مشفرة للبيانات.
- اختبر المبيعات والمشتريات والمخزون والنسخ الاحتياطي على بيانات تجريبية قبل استخدامها تجاريًا.
